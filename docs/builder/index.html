1. Pick a starting point

Scaffolds are full nano-zyrkels. Themes restyle a scaffold. Examples are bite-sized snippets you can lift into any repo.

    Generate a nano-zyrkel without a single command

    Choose any scaffold, theme or example on the left. Fill in a handful of fields. Download a zip and push it to GitHub. The repo it produces is wired up with the same reusable workflows the rest of the SDK uses.

    • Schemas come straight from templates/manifest.json
    • Slot substitution happens in your browser — no server round trip
    • The builder is itself a nano-zyrkel hosted on GitHub Pages
