# theme-cinematic

Dark, full-bleed, ambient gradient. Built for showcase / portal
nano-zyrkels and demo pages. The base CSS stays generic so any
particle or animation crate can layer on top of it.

## Use it

```bash
cp -r theme-cinematic/docs/* my-nano-zyrkel/docs/
```

Recommended `wasm-core` profile: `data` for the basics. Add a
user-repo crate (e.g. with a particle system) if you want the
cinematic intro that the showcase repo ships.
