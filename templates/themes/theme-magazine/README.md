# theme-magazine

Editorial layout with large Playfair Display headlines and a two-column
serif body. Built for newsletters and research digests
(literature-alert is the obvious match).

## Use it

```bash
cp -r theme-magazine/docs/* my-nano-zyrkel/docs/
```

Recommended `wasm-core` profile: `data` (no charts) or `viz-basic` if
you want a single hero chart inside the editorial body.
